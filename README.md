# 🤖 Eduka - Agente Inteligente Financeiro

## 📌 Sobre o Projeto

O **Eduka** é um agente inteligente desenvolvido para auxiliar usuários na organização financeira, utilizando dados simulados para gerar insights, identificar padrões de gastos e sugerir melhorias.

---

## 🎯 Objetivo

Ajudar pessoas a entender melhor suas finanças e tomar decisões mais conscientes, de forma simples, segura e personalizada.

---

## ⚙️ Como Funciona

O agente utiliza:

* Dados mockados (transações, perfil e histórico)
* Processamento via modelo de linguagem (LLM)
* Interface interativa com Streamlit

Fluxo básico:
Usuário → Interface → Agente → Dados → Resposta

---

## 🚀 Funcionalidades

* Análise de gastos
* Identificação de padrões financeiros
* Sugestões baseadas no perfil do usuário
* Respostas contextualizadas e seguras

```bash
git clone <repo>
cd src
pip install -r requirements.txt
streamlit run app.py
```

---

## 🔒 Boas Práticas

* Não inventa dados
* Responde apenas com base no contexto
* Evita recomendações inadequadas ao perfil

---

## ⚠️ Limitações

* Utiliza dados simulados
* Não realiza operações financeiras reais
* Não substitui consultoria profissional
